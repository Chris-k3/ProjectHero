# Animation asset credits

Zomb-Band author: **HUNK**.

The playing loops and violin-bow display prop in this release are adapted from the user-provided `PlayItInstruments.rar`, whose metadata identifies it as **Play it! Playable musical instruments**, Mod ID `PlayItInstruments`. The supplied metadata does not name an individual animation author; no individual credit has been invented.

Included families: guitar, violin, flute, harmonica, saxophone, trumpet and keytar. Each includes standing, chair and ground variants. Acoustic/electric guitars, bass and banjo share the guitar-style motion. The violin bow is a cosmetic hand prop, not an inventory item or required accessory.

The files are namespaced as `ZombBand...` / `Bob_ZombBand...` to avoid colliding with the original mod. GLB animation names, XML references and the bow model/texture paths were updated together. Original skeletons, animation channels, bone weights and timing were retained.

No PlayIt song, MIDI, UI, networking, skill, zombie-noise or sample-library scripts are loaded by this integration. Zomb-Band's own audio, song charts, session logic and bounded zombie noise remain in control. Enabling the full PlayIt mod is not required.

`ANIMATION_ASSETS.json` records source and target animation filenames and hashes.
